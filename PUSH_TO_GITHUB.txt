═══════════════════════════════════════════════════════════════
  STEP-BY-STEP GUIDE TO PUSH UOMS PROJECT TO GITHUB
═══════════════════════════════════════════════════════════════

BEFORE YOU START:
-----------------
1. Make sure you have a GitHub account
2. Make sure Git is installed on your system
3. Have your GitHub username and password/token ready


STEP 1: CONFIGURE GIT (First Time Only)
----------------------------------------
Open Command Prompt or PowerShell and run:

git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"

Replace "Your Name" and "your.email@example.com" with your actual details.


STEP 2: CREATE GITHUB REPOSITORY
---------------------------------
1. Go to: https://github.com
2. Click the "+" icon in top-right corner
3. Click "New repository"
4. Fill in:
   - Repository name: uoms
   - Description: University Order Management System - Laravel 12
   - Choose: Public or Private
   - DO NOT check "Initialize with README"
   - DO NOT add .gitignore
   - DO NOT add license
5. Click "Create repository"
6. KEEP THIS PAGE OPEN - you'll need the URL


STEP 3: INITIALIZE GIT IN YOUR PROJECT
---------------------------------------
Open Command Prompt/PowerShell in your project folder:

cd D:\INSTALL LARAVEL\UOMS\uoms

Then run:

git init


STEP 4: ADD ALL FILES TO GIT
-----------------------------
git add .


STEP 5: CREATE FIRST COMMIT
----------------------------
git commit -m "Initial commit: UOMS Laravel 12 project with role-based authentication"


STEP 6: RENAME BRANCH TO MAIN (if needed)
------------------------------------------
git branch -M main


STEP 7: CONNECT TO GITHUB
--------------------------
Replace "yourusername" with your actual GitHub username:

git remote add origin https://github.com/yourusername/uoms.git

Example:
git remote add origin https://github.com/johnsmith/uoms.git


STEP 8: PUSH TO GITHUB
-----------------------
git push -u origin main

You will be prompted for:
- Username: Enter your GitHub username
- Password: Enter your Personal Access Token (NOT your GitHub password)


IF YOU DON'T HAVE A PERSONAL ACCESS TOKEN:
-------------------------------------------
1. Go to: https://github.com/settings/tokens
2. Click "Generate new token" → "Generate new token (classic)"
3. Give it a name: "UOMS Project"
4. Select scope: "repo" (check the box)
5. Click "Generate token"
6. COPY THE TOKEN (you won't see it again!)
7. Use this token as your password when pushing


STEP 9: VERIFY ON GITHUB
-------------------------
1. Go to: https://github.com/yourusername/uoms
2. You should see all your files
3. README.md should be displayed on the main page

═══════════════════════════════════════════════════════════════
  TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

ERROR: "remote origin already exists"
SOLUTION:
git remote remove origin
git remote add origin https://github.com/yourusername/uoms.git


ERROR: "failed to push some refs"
SOLUTION:
git pull origin main --allow-unrelated-histories
git push -u origin main


ERROR: "Support for password authentication was removed"
SOLUTION:
You need to use a Personal Access Token instead of your password.
Follow the "IF YOU DON'T HAVE A PERSONAL ACCESS TOKEN" section above.


ERROR: "Permission denied"
SOLUTION:
Make sure you're using the correct GitHub username and token.
