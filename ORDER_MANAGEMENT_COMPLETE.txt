1. ORDER FLOW (USER SIDE - P4)
================================================================================

STEP 1: Browse Products
- User logs in → /user/dashboard
- Navigate to Products menu
- Browse available products
- Search and filter by category

STEP 2: Add to Wishlist
- Click "Add to Wishlist" button on any product
- Products are saved to wishlist
- Wishlist count badge shows in sidebar

STEP 3: View Wishlist
- Navigate to Wishlist menu
- See all wishlist items with:
  * Product image
  * Product name
  * Category
  * Available stock
  * Remove button

STEP 4: Place Order from Wishlist
- Click "Place Order from Wishlist" button
- Enter quantity for each product (with validation)
- Quantity cannot exceed available stock
- Add optional remarks
- Click "Place Order"

STEP 5: Order Placed
- Order number auto-generated: UOMS-YYYY-0001
- Total items calculated automatically
- Wishlist cleared automatically
- Status set to "pending"
- Redirect to Order History

STEP 6: View Order History
- See all orders with:
  * Order number
  * Date
  * Total items
  * Status badge (color-coded)
  * View details button
- Search by order number
- Filter by status
- Pagination

STEP 7: View Order Details
- Order information
- Status timeline
- Ordered products table
- User remarks

3. DATABASE STRUCTURE
================================================================================

TABLE: orders
Fields:
- id (primary key)
- user_id (foreign key → users)
- order_number (unique, format: UOMS-YYYY-0001)
- total_items (integer)
- status (enum: pending, approved, rejected, processing, completed)
- remarks (text, nullable)
- created_at
- updated_at

TABLE: order_items
Fields:
- id (primary key)
- order_id (foreign key → orders)
- product_id (foreign key → products)
- quantity (integer)
- created_at
- updated_at

================================================================================
4. RELATIONSHIPS
================================================================================

User Model:
- hasMany Orders
- hasMany Wishlists

Order Model:
- belongsTo User
- hasMany OrderItems

OrderItem Model:
- belongsTo Order
- belongsTo Product

Product Model:
- hasMany OrderItems
- hasMany Wishlists

Wishlist Model:
- belongsTo User
- belongsTo Product

9. STATUS FLOW
================================================================================

Order Status Progression:

1. PENDING (Yellow Badge)
   ↓
2. APPROVED (Green Badge) or REJECTED (Red Badge)
   ↓
3. PROCESSING (Blue Badge) [if approved]
   ↓
4. COMPLETED (Dark Badge)

Admin can update status at any time.
User sees status updates in real-time.
